# Карта кейсов SpeedWash

Интерактивный блок в стиле [speedwash.ru](https://speedwash.ru): Manrope, фирменный оранжевый `#FE6219`, светлая векторная карта, выделение регионов, фотографии и адреса объектов.

**[Открыть карту](https://pvchernev.github.io/speedwash/projects/cases-map/)** · **[Код для Тильды](tilda-embed.html)**

## Установка на Тильду

Добавьте блок **T123 «HTML-код»** в нужное место страницы и вставьте:

```html
<div data-speedwash-map></div>
<script defer src="https://pvchernev.github.io/speedwash/projects/cases-map/speedwash-map.js"></script>
```

Опубликуйте страницу. В редакторе Тильды скрипты могут не выполняться; проверять нужно опубликованную страницу. [Инструкция Тильды по HTML-коду](https://help-ru.tilda.cc/html).

JS, CSS, контуры регионов и резервный каталог загружаются с GitHub Pages. При изменении файлов в ветке `main` GitHub Pages публикует обновление. Код блока на Тильде менять не нужно. Обновление публикации и кеша может занять несколько минут.

## Что умеет карта

- Нажатие на регион или круг со счётчиком показывает его кейсы. Повторное нажатие снимает выбор.
- Карточка открывает страницу проекта в новой вкладке с `noopener noreferrer`.
- Фильтры по стране и модели, поиск по городу, региону, адресу и названию.
- Выбор региона через выпадающий список, доступный с клавиатуры и на телефоне.
- Масштабирование кнопками; на компьютере увеличенную карту можно перемещать мышью.
- Адаптивное расположение карточек под картой на телефонах.
- Анимации отключаются при системной настройке уменьшения движения.
- Shadow DOM изолирует оформление блока от CSS Тильды. Внешний SDK карты и API-ключи не требуются.

## Откуда берутся кейсы

Используется тот же открытый каталог, что и на странице [speedwash.ru/cases](https://speedwash.ru/cases). Раздел каталога: `676741207832`, блок: `815255442`. На момент сборки — **47 кейсов**, **28 групп по регионам**, **3 страны**. Это число опубликованных кейсов; один кейс может описывать несколько объектов.

При открытии страницы на домене SpeedWash виджет запрашивает актуальные данные каталога: название, город, страну, модель, описание с адресом, первую фотографию и прямую ссылку. Пагинация учитывается; лимит первой страницы не обрезает список.

Тильда ограничивает этот каталог своим доменом. Поэтому в демо на GitHub Pages, на другом домене и при недоступности каталога показывается резервный файл `assets/cases.json`. Его дата указана под картой. API каталога — публичный механизм опубликованной Тильды, без официальной гарантии стабильности; резервная копия позволяет сохранить работоспособность при изменениях API.

Обновить резервную копию:

```sh
node projects/cases-map/scripts/refresh-cases.mjs
git add projects/cases-map/assets/cases.json
git commit -m "Обновить резервный каталог кейсов"
git push
```

CommerceML не используется. Логины, пароли и закрытые данные в репозитории отсутствуют.

## Добавление новых проектов и регионов

Проекты в уже известных городах появятся при следующем открытии опубликованной страницы SpeedWash. Если город новый, укажите у товара опцию или характеристику **«Регион»** с названием, например `Самарская область`, либо кодом региона, например `RU-SAM`. Векторная геометрия и названия российских регионов уже включены.

Для существующих кейсов регион определён по полю «Город» и справочнику `cityRegions` в `assets/map.json`. Для частного проекта, названного «Москва», но описанного как объект в Подмосковье, задано отдельное соответствие Московской области. Явное поле «Регион» в каталоге имеет приоритет над справочником. Варианты «Республика Башкортостан», «Удмуртская Республика», «Республика Хакасия», «ХМАО» также распознаются.

Новый неизвестный город без региона остаётся в поиске и общем списке, в пункте **«Другие города»**. Он не получает выдуманные координаты. Для нового региона Беларуси или Казахстана добавьте группу в `scripts/build-map.mjs` и пересоберите карту.

Круги показывают **группы кейсов в регионе**, а не точные точки входа в автомойки. Близкие круги раздвигаются для читаемости и соединяются с исходной точкой тонкими линиями. Точные адреса взяты из каталога и показаны в карточках. Автоматического геокодирования адресов и платного картографического API нет. Названия стран в фильтрах повторяют поля каталога.

Чтобы сразу показать конкретный регион:

```html
<div data-speedwash-map data-region="RU-BA"></div>
<script defer src="https://pvchernev.github.io/speedwash/projects/cases-map/speedwash-map.js"></script>
```

## Файлы и разработка

| Файл | Назначение |
| --- | --- |
| `speedwash-map.js` | Загрузка данных, фильтры, карта, карточки |
| `speedwash-map.css` | Оформление и адаптивная верстка |
| `assets/map.json` | Векторные контуры, точки групп и соответствия городов |
| `assets/cases.json` | Резервная копия публичных кейсов |
| `tilda-embed.html` | Готовый короткий код вставки |
| `index.html` | Демо |

Из корня репозитория: `npm run serve`, затем откройте `http://localhost:8765/projects/cases-map/`. Для просмотра сборка не нужна. Пересборка геометрии из корня: `npm ci && npm run build:map` (Node.js 20+).

Все пути в таблице выше указаны относительно `projects/cases-map/`. Этот проект входит в общий репозиторий [SpeedWash](../../README.md).

Геометрия карты: [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/), публичное достояние. Исходные данные: [admin 0](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson) и [admin 1](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_1_states_provinces.geojson). Проекция: conic equal area, формируется при сборке через `d3-geo`, браузер не загружает библиотеку. Фотографии, адреса и ссылки принадлежат SpeedWash и остаются на его CDN.
